Manual de uso

De cero a jugar, sin pasos innecesarios

Todo se gestiona desde la interfaz. Estos son los seis pasos que cubren el uso habitual del launcher.

1

Primer arranque

Elige la carpeta de datos del launcher y escribe tu nombre de jugador. Se crea un perfil offline con UUID determinista.

2

Elige la versión

Abre el selector en Jugar y busca por versión o loader. Puedes mantener varios perfiles de la misma versión base.

3

Instala un loader

OptiFine se instala desde su tarjeta de versión. Forge, Fabric y NeoForge se instalan desde Ajustes → Mods.

4

Añade mods

En Ajustes → Mods puedes añadir archivos .jar, consultar sus metadatos y retirarlos. El launcher avisa de incompatibilidades conocidas.

5

Configura la cuenta

El perfil offline está pensado para uso personal y partidas de un jugador. Para servidores oficiales, vincula una cuenta Microsoft.

6

Ajusta el rendimiento

Elige memoria RAM, prioridad, núcleos y recolector de basura. La opción de optimización recomienda valores según el hardware.

Rendimiento

Tu equipo, tus reglas

Controla los recursos del juego sin editar archivos y guarda la configuración junto al resto de tus ajustes.

Memoria RAM

Adaptativa

El límite del selector se calcula según la memoria del equipo, reservando recursos para el sistema.

Prioridad del proceso

5 niveles

Elige entre Reposo, Baja, Normal, Alta y Muy alta para el proceso del juego en Windows.

Afinidad de CPU

N núcleos

Limita el juego a un número de núcleos lógicos o permite que use todos los disponibles.

Recolector de basura

G1 · Serial · Parallel

Serial para equipos modestos; G1 para un rendimiento más constante en equipos potentes.

Argumentos JVM

Personalizables

Añade opciones propias. Si defines otro recolector, el launcher advierte de una posible duplicidad.

Optimización rápida

Según hardware

Analiza el procesador, la memoria y la GPU, y aplica recomendaciones de RAM y GC.

Consejo: para la mayoría de equipos, entre 2 y 4 GB de RAM son suficientes. Asignar más memoria de la disponible puede ralentizar el sistema.

Ayuda

Preguntas frecuentes

Respuestas breves a las dudas más habituales antes de descargar.

¿Necesito una cuenta de Microsoft para jugar?
No para el perfil offline, que está pensado para uso personal y partidas de un jugador. Para acceder a servidores oficiales o a Realms necesitas una cuenta válida de Minecraft, que puedes vincular desde la pestaña Cuenta con un código de dispositivo.
¿El launcher descarga archivos del juego?
Sí. AZeroCraft no incluye ni redistribuye archivos de Minecraft: descarga el cliente, las bibliotecas, los nativos y los recursos desde los servidores oficiales de Mojang cuando los necesitas.
¿Dónde se guardan mis mundos y ajustes?
En la carpeta oficial .minecraft de Windows, compartida con el launcher de Mojang. AZeroCraft no modifica tus opciones de juego ni mueve tus mundos. Los ajustes propios del launcher se guardan en la carpeta de datos que elijas.
¿Funciona sin conexión a Internet?
El modo sin conexión permite usar los archivos que ya están en la caché local sin consultar el manifiesto ni verificar hashes. Los archivos que falten no se podrán descargar, así que el perfil debe estar preparado previamente.
¿Por qué el launcher avisa de un mod incompatible?
Porque el archivo declara requisitos de versión de Minecraft, de Java o de un loader que no coinciden con el perfil seleccionado. La comprobación depende de los metadatos disponibles en cada mod; si el aviso aparece, usa el archivo adecuado o cambia de perfil.
