REGISTRO

Funciones

Todo lo que un launcher debe hacer, sin ruido

Instalación verificada, Java automático, OptiFine y un modo offline que funciona en servidores y singleplayer.

⬇

Instalación automática

Descarga el cliente, las librerías, los nativos y los assets directamente de Mojang con verificación SHA-1/SHA-256 y reanudación implícita por archivo.

☕

Java automático

Detecta los JRE instalados y elige el compatible con cada versión. Si falta, descarga Temurin (Eclipse Adoptium) sin intervención.

✦

OptiFine integrado

Aplica el instalador oficial en modo headless y crea un perfil propio que aparece en la lista de versiones junto a las vanilla.

◎

Modo offline real

UUID v3 determinista idéntico al de nameUUIDFromBytes de Java: tu mundo y tu skin offline se mantienen siempre iguales.

⚡

Conexión rápida

Escribe servidor.net:25565 y entra directo al servidor al arrancar. Compatible con IPv6.

🗂

Portable de verdad

Todo vive en ./data junto al ejecutable. Copia la carpeta a un USB y sigue jugando. En instalación de sistema usa %APPDATA% automáticamente.

Control de recursos

Prioridad del proceso

5 niveles

Reposo, Baja, Normal, Alta y Muy alta vía SetPriorityClass en Windows.

N núcleos

SEGURIDAD

Extracción de ZIP sin path traversal, verificación de hashes en cada descarga, URLs solo de dominios oficiales.

CONFIABILIDAD

Reintentos con backoff, cancelación cooperativa, escritura atómica de JSON, caché de manifiestos de 6 h.

RENDIMIENTO

12 descargas en paralelo, UI en hilo principal + workers QThread, proceso de juego desacoplado del launcher.

Compilar

Desde código fuente

Desarrollo local en Python puro — sin Node, sin Docker, sin sorpresas.

# 1. Entorno e dependencias
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt

# 2. Ejecutar
python main.py          # o: python -m azero
Release

Build de producción

Ejecutable nativo + instalador + publicación en GitHub Releases.

# Ejecutable onedir (PyInstaller)
.\build.ps1

# + Instalador Inno Setup (requiere Inno Setup 6)
.\build.ps1 -Installer

# O publicar todo en GitHub Releases:
git tag v1.0.0
git push origin v1.0.0

Verificación

python -m unittest discover -s tests -v   # tests unitarios
python tools\verify_version.py 1.12.1   # QA real: manifiesto → assets → URLs
