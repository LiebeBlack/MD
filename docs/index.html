Funciones

Todo lo que un launcher debe hacer, sin ruido

Selector de versiones agrupado por loader — Vanilla, OptiFine, Forge, Fabric y NeoForge —, varios perfiles por versión base y detección de mods incompatibles antes de lanzar.

⬇

Instalación automática

Descarga el cliente, las librerías, los nativos y los assets directamente de Mojang con verificación SHA-1/SHA-256 y reanudación implícita por archivo.

☕

Java automático

Detecta los JRE instalados y elige el compatible con cada versión. Si falta, descarga Microsoft OpenJDK LTS sin intervención.

✦

OptiFine integrado

Aplica el instalador oficial en modo headless y crea un perfil propio que aparece en la lista de versiones junto a las vanilla.

◈

Forge, Fabric y NeoForge

Instala los tres loaders desde Ajustes → Mods, en formatos antiguos y modernos, con varios perfiles por versión base (p. ej. 1.21.1 Forge y Fabric a la vez). NeoForge se detecta correctamente sin confundirlo con Forge.

▦

Selector de versiones agrupado

Explora las versiones por categoría de loader, familia, versión base y perfil. El buscador integrado facilita encontrar una versión y mantener varios perfiles del mismo juego organizados.

⚠

Compatibilidad de mods

Antes de iniciar el juego, el launcher revisa las dependencias declaradas en los mods y avisa si detecta incompatibilidades con la versión de Minecraft o el loader seleccionado. La comprobación depende de los metadatos disponibles en cada archivo.

◎

Modo offline real

El perfil offline genera un UUID v3 determinista, compatible con nameUUIDFromBytes de Java. El mismo nombre produce siempre el mismo UUID.

⚡

Conexión rápida

Escribe servidor.net:25565 y entra directo al servidor al arrancar. Compatible con IPv6.

🗂

Portable de verdad

En modo portable, los datos propios del launcher se guardan junto al ejecutable; en una instalación para el usuario, se guardan en la ubicación de datos de la aplicación. La carpeta oficial .minecraft permanece compartida con el launcher de Mojang.

☁

Cuenta Microsoft opcional

Vincula una cuenta Microsoft mediante un código de dispositivo, sin introducir la contraseña en el launcher. El inicio de sesión oficial es opcional.

🕘

Historial completo

Consulta las versiones instaladas, el espacio que ocupan, las descargas recientes y las sesiones de juego. El historial se guarda localmente en SQLite.

🧠

Ajustes según tu hardware

El selector de RAM y las recomendaciones tienen en cuenta la memoria y el procesador del equipo. Puedes ajustar el recolector de basura, la prioridad del proceso y la afinidad de CPU; la optimización rápida recomienda valores de RAM y GC según el hardware.

Manual de uso

De cero a jugando en minutos

Guía rápida de cada función del launcher. Todo se gestiona desde la interfaz; no hace falta tocar archivos.

1 · Primer arranque

  • Elige dónde guardar los datos propios del launcher. La carpeta oficial .minecraft se mantiene compartida.
  • Escribe tu nombre de jugador — el perfil offline se crea solo, con UUID determinista.
  • Pulsa Jugar: la primera vez descarga cliente, librerías, nativos y assets automáticamente.

2 · Elegir versión

  • El selector agrupa por loader: Vanilla, OptiFine, Forge, Fabric, NeoForge.
  • Dentro, por familia (1.21.x, 26.x) y versión base.
  • Escribe en el buscador para filtrar (fabric, 26.3…).
  • Puedes tener varios perfiles del mismo juego a la vez.

3 · Instalar un loader

  • OptiFine: tarjeta Versión en Jugar → selecciona el .jar oficial.
  • Forge / Fabric / NeoForge: Ajustes → Mods → botón del loader, elige versión base y release.
  • La instalación es silenciosa; el perfil aparece en el selector al terminar.

4 · Añadir mods

  • Ajustes → Mods → Añadir .jar (o copia los .jar a .minecraft/mods).
  • El launcher muestra nombre y versión de cada mod.
  • Antes de lanzar avisa si algún mod no es para tu versión de Minecraft o Java — revísalo en el estado de Jugar.

5 · Cuenta y multijugador

  • Perfil offline: nombre propio para uso personal y partidas de un jugador, de acuerdo con las condiciones de Minecraft.
  • Microsoft: Cuenta → Iniciar sesión. Completa la autenticación con el código de dispositivo, sin introducir la contraseña en el launcher.
  • Escribe servidor:25565 en Jugar para entrar directo al servidor.

6 · Rendimiento

  • Jugar → tarjeta Ajustes rápidos: RAM (2–4 GB suele bastar) y presets.
  • Ajustes → Rendimiento: prioridad del proceso, núcleos, recolector GC (Serial/G1/Parallel), argumentos JVM.
  • "Optimizar para este equipo" aplica RAM y GC según tu hardware detectado.
Solución de problemas

Preguntas frecuentes

El launcher avisa de mods incompatibles

La carpeta mods se comparte entre versiones. Un mod puede declarar requisitos para una versión concreta de Minecraft o un loader; el launcher avisa cuando detecta una incompatibilidad en los metadatos disponibles. Usa los mods adecuados para el perfil seleccionado.

Minecraft termina al iniciar (código ≠ 0)

Abre la carpeta de registros desde la sección Versiones y busca la línea Caused by. Entre las causas frecuentes están los mods incompatibles, una versión de Java no compatible o los argumentos JVM personalizados.

¿Puedo llevarlo en un USB?

Sí: descarga el Portable (.zip), descomprímelo donde quieras y ejecuta AZeroCraft.exe. Los datos se guardan en ./data junto al exe; la carpeta .minecraft sigue siendo la oficial de Windows.

No hay conexión / descargas fallan

Activa Modo sin conexión en Ajustes para usar los archivos de la caché local sin consultar el manifiesto ni verificar hashes. Los archivos que falten no se podrán descargar, así que el perfil debe contar con los recursos necesarios.

No aparece una versión o snapshot

Los snapshots y las versiones antiguas están ocultos por defecto. Activa Mostrar todas las versiones en Ajustes y búscalos en el selector (por ejemplo, 25w14a).

¿Dónde están mis mundos y ajustes?

La carpeta oficial .minecraft (%APPDATA%\.minecraft) sigue compartida con el launcher de Mojang y contiene tus mundos, paquetes de recursos, shaders, options.txt y mods. AZeroCraft no modifica las opciones de juego.

Control de recursos

Tu PC, tus reglas

Ajusta exactamente cuántos recursos puede consumir el juego mientras juegas o antes de lanzar.

Memoria RAM

Adaptativa

El límite del selector se calcula según la memoria del equipo y reserva recursos para el sistema. El launcher configura la memoria inicial y máxima de Java a partir del valor elegido.

Prioridad del proceso

5 niveles

Elige entre Reposo, Baja, Normal, Alta y Muy alta para ajustar la prioridad del proceso del juego en Windows.

Afinidad de CPU

N núcleos

Limita el juego a un número determinado de núcleos lógicos o deja que use todos los disponibles.

Recolector de basura

G1 · Serial · Parallel

Elige el GC de la JVM: Serial para equipos modestos, G1 para máximo rendimiento.

Argumentos JVM

Libres

Configura argumentos JVM personalizados en Ajustes → Java. Si especificas otro recolector de basura, el launcher avisa de que puede entrar en conflicto con el ajuste elegido.

Java automático

Microsoft OpenJDK

Detecta los JRE instalados, elige el compatible con cada versión (8 → 25) y descarga Microsoft OpenJDK LTS si falta.

Optimización en un clic

Hardware

«Optimizar para este equipo» analiza el procesador, la memoria y la GPU, y aplica recomendaciones de RAM y del recolector de basura.

Hardware inteligente

CPU · GPU · SSE4.2

Consulta información del procesador, la GPU, la memoria y las instrucciones compatibles del equipo.

SEGURIDAD

Extracción de ZIP sin path traversal, verificación de hashes en cada descarga, URLs solo de dominios oficiales.

CONFIABILIDAD

Reintentos con backoff, cancelación cooperativa, escritura atómica de JSON, caché de manifiestos de 6 h.

RENDIMIENTO

12 descargas en paralelo, UI en hilo principal + workers QThread, proceso de juego desacoplado del launcher.
