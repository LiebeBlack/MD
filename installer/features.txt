AZeroCraft Launcher — Funciones

- Minecraft Java Edition 1.7 hasta la versión actual, con descargas oficiales.
- Loaders: Forge, Fabric, NeoForge y OptiFine, varios perfiles por versión.
- Cuentas Microsoft (código de dispositivo) y perfiles offline.
- Java automático: detecta runtimes y descarga Microsoft OpenJDK (LTS) si falta.
- Mods de Fabric/Forge/NeoForge con aviso de incompatibilidades.
- Rendimiento: RAM, prioridad, recolector GC y núcleos.
- Comparte versiones, mundos, mods y resourcepacks con .minecraft.

Instalación por usuario o para todo el equipo, con accesos directos opcionales.
